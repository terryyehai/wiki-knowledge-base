## 核心概念

### Hermes Agent 跟一般 AI 的差別
- **一般 AI**：你問一句他答一句，答完就完事，沒有記憶
- **Hermes Agent**：會自己動手做事，讀寫檔案、跑指令、照時間執行任務
- **與 OpenCat（Browser Use）相比**：OpenCat 四肢發達但很笨，做完就忘；Hermes 腦子好、記性強，會累積對你的理解

### 為什麼適合當第二大腦
1. **純文字 Markdown 檔案**：就算哪天不用 Hermes 了，筆記全部可以帶走
2. **會自我進化**：Agent 會主動不斷更新大腦，越用越聰明
3. **按你的規則做事**：把你的寫作風格、選題邏輯、原則寫成說明書，Agent 越用越像你的分身

## 六個常用 Use Case

### 1. 記錄靈感
語音丟給 WhatsApp/Discord → 自動歸類到 YouTube 靈感資料夾

### 2. 記帳
吃完飯拍照，發給 Agent → 自動分類，月底/年終隨時查詢每類支出

### 3. 飲食記錄（血糖控制）
拍照發給 Agent → 自動分析食物、預估卡路里、主動提醒碳水攝取

### 4. 讀書筆記
看到好句子，WhatsApp/Discord 語音說 → 自動儲存，之後用自然語言召回

### 5. 關係維護
誰的小孩幾歲、上次答應過什麼事 → 丟給 Agent，下次聯絡前問他

### 6. 自動收集整理資訊
設定定時任務，每天早上六點自動抓 AI/電商相關新聞 → 推送到 Discord

## 不建議交給 AI 的事情

### 機密資訊
密碼、帳號、證件（身份證、護照）

### 個資敏感資料
取決於你接的模型是否對資料落地有疑慮

### 涉及個人風格的內容
- YouTube 影片旁白和配音（觀眾認得的是你的聲音和風格）
- 選題、最終拍板（這些是靠經驗、直覺，AI 無法取代）

## 結論
把雜活自動化外包給 AI Agent，省下時間投入真正屬於你自己的東西：品味、經驗、判斷、聲音、風格。
